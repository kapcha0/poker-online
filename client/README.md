# client/ — Unity-клиент

Unity-проект Android-клиента «Poker Онлайн».

- Движок: Unity 6 LTS (6000.3.10f1) + модули Android Build Support / SDK & NDK / OpenJDK.
- Открывать в Unity Hub → Add → выбрать эту папку.
- Игровая логика не пишется здесь напрямую — она берётся из `../shared`.

> Проект Unity создаётся на **этапе 2**. До этого папка пустая.
