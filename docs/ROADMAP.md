# ROADMAP.md — дорожная карта и журнал прогресса

## Принятые решения (этап 0)

| Вопрос | Решение |
|--------|---------|
| Дисциплина покера | Texas Hold'em (только) |
| Режимы | Кэш-столы (этап 2), турнирные Sit&Go (этап 4–5), MTT — онлайн-этап |
| Движок | Unity LTS (C#) |
| IDE | Visual Studio 2022 Community |
| Эмулятор Android | Android Studio Emulator |
| Социалка MVP | Статистика профиля + локальный лидерборд (чат/друзья — позже) |
| Монетизация | Без рекламы; внутриигровые покупки коинов + косметика профиля |
| Передача валюты между игроками | Нет |
| Хостинг | Free-тир на разработке, платный — к релизу |
| Email-рассылка | Free-сервис (Resend/Brevo) — к этапу 7 |
| Название (рабочее) | **Poker Онлайн** |
| Визуальный стиль | Минимализм |
| Языки | ru / en (закладываем с этапа 2, полный перевод — к релизу) |
| Google Play Developer | Пока нет, к этапу 10 |
| GitHub | https://github.com/kapcha0 |

### Требования к качеству (чего НЕ должно быть в игре)
- Донат не ломает баланс (никакого pay-to-win).
- Нет лагов.
- Нет читеров.
- Рекламы в игре нет вообще.
- Прогресс не теряется.
- Понятные правила новичку.
- Быстрый вход в игру.
